# Bonus — methane-OGI simulation and detection demo

Runnable companion code for the report at `../methane-ogi-payload-report.md`.

## What's here

- `contrast_simulation.py` — Beer-Lambert + Planck simulation. Generates the two sensitivity plots embedded in §4 and §8 of the report (apparent ΔT vs column density, CL_min vs scene ΔT). Calibrated to literature-cited NETD and absorption-coefficient values; deterministic; `~1 s` runtime.
- `detection_demo.py` — synthetic frames + detection pipeline + benchmark. Runs the load-bearing core of the §7 algorithm pipeline (rolling-median temporal background, frame differencing, MAD-based adaptive threshold, connected-components extraction) against three synthetic clips and emits precision/recall plus before/after still PNGs.
- `data/facts.md` — cited-numbers source-of-truth that grounds every quantitative claim in the report.
- `data/precedent-search.md` — log of the precedent search supporting §1 / §4.5.
- `data/low-level-talking-points.md` — interview cheat sheet pairing with Appendix E (sensor bus, RT scheduling, drivers, DMA, MCU, bring-up tooling, language fluency, "things to be honest about", and pivot moves).
- `tests/` — pytest test suites (47 scenarios total).

## Requirements

- Python 3.11+ (Python version pinned in `.python-version`).
- [`uv`](https://docs.astral.sh/uv/) for dependency and project management. Pure-uv workflow — do not use `pip` or `uv pip`.

## Setup

From this directory:

```sh
uv sync
```

This creates the venv and installs the locked dependencies (`numpy`, `scipy`, `matplotlib`, `pytest`).

## Run

Generate the simulation plots (used in report §4 and §8):

```sh
uv run python contrast_simulation.py
```

Outputs land in `outputs/`:
- `plot_apparent_dT_vs_CL.png` — apparent ΔT vs column density at multiple ΔT values, with NETD reference lines for cooled MWIR and uncooled LWIR
- `plot_CL_min_vs_dT.png` — minimum detectable column density vs scene ΔT for both technologies, with the operational gap annotated at ΔT = 5 K

Run the detection-pipeline demo (used in report §8 and Appendix B):

```sh
uv run python detection_demo.py
```

Outputs land in `outputs/`:
- `benchmark_results.json` — precision, recall, true/false positive/negative counts per scenario
- `frame_pre_detection.png` and `frame_post_detection.png` — example frames showing the pipeline's detection behavior

The benchmark JSON omits wall-clock latency to keep the artifact reproducible across machines. Latency is printed to stdout instead — typical on a modern laptop is 15-20 ms per frame for the 320×256 synthetic clips at the demo's settings.

## Test

Run the full test suite (27 simulation tests + 20 demo tests):

```sh
uv run pytest tests/
```

Test development was done test-first: every assertion was written before its implementation. The tests pin down:

- Beer-Lambert sanity (zero-CL → unit transmittance, large-CL → opacity, small-CL linearization)
- Apparent ΔT properties (zero-ΔT → zero contrast, saturation at large CL, sign symmetry)
- CL_min ordering (lower NETD → lower CL_min, higher α → lower CL_min, divergence when ΔT ≤ NETD)
- Planck radiance correctness (Wien-displacement peak at 9.7 µm for 300 K, monotonic increase with T)
- The operational-gap claim (uncooled / cooled CL_min ≈ 5× at ΔT = 5 K — the credibility-multiplier story for the report's §4)
- Synthetic scene generation (determinism, plume drift, perturbation effects, ground-truth bbox validity)
- Pipeline behavior (warmup, easy-scenario quality, sub-threshold safety, static-distractor rejection)
- End-to-end deterministic plot/JSON generation

## Reproducibility notes

- Every script uses fixed `numpy.random` seeds so the generated data and JSON are deterministic.
- PNG plots are expected to be visually identical in the locked/tested environment; bit-for-bit PNG identity can vary across platforms, fonts, or Matplotlib builds. `matplotlib`'s `svg.hashsalt` is pinned for SVG-ID determinism if SVG output is added later.
- The benchmark JSON intentionally omits per-frame latency because wall-clock measurement varies across machines and would defeat reproducibility.
- Re-running `uv run python contrast_simulation.py` regenerates the embedded report figures from scratch; cached lockfile + pinned dependencies prevent dependency drift, while exact raster bytes are guaranteed only in the tested environment.

## Caveat on the demo's precision/recall

The synthetic data is generated by the same Beer-Lambert plume model the detector implicitly recovers. The reported precision/recall numbers (1.00/1.00 easy, 0.89/0.42 medium, 1.00/0.00 hard) are a **controlled-conditions sanity check** that the pipeline functions as designed under the assumed plume model. They are an upper bound on real-OGI performance, **not** a field-deployment claim. Validation against real OGI footage is named as future work in report §9 and Appendix B.2.
